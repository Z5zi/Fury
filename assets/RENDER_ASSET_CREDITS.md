# Optional rendering assets

**Powered by Poly Haven** — https://polyhaven.com

The optional high-detail coastal scene uses these original Poly Haven assets,
downloaded separately by `scripts/fetch-render-assets.ps1`:

- Modular Wooden Pier: https://polyhaven.com/a/modular_wooden_pier
- Island Tree 01: https://polyhaven.com/a/island_tree_01

Both are CC0: https://polyhaven.com/license

The source files are free from Poly Haven. The lock file records the exact 2K
glTF packages and SHA-256 hashes used for this rendering fixture. Downloaded
models and textures live in `out/assets/` and are not part of the Git source
history. The procedural cabin, boat and other test-scene geometry are Fury code.

The supplied GTA visual reference is not redistributed or used as texture data.
