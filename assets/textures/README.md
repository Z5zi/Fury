# Vaultline albedo textures (5.2.0)

Original procedural textures — **no third-party / Rockstar / GTA IP**.

| File | Use |
|------|-----|
| `crate_wood.png` / `.ppm` | Wood crates (`TextureSlot::Wood`) |
| `barrel_metal.png` / `.ppm` | Metal barrels (`TextureSlot::BarrelMetal`) |
| `asphalt.png` / `.ppm` | Roads / street ground (`TextureSlot::Asphalt`) |

Engine prefers PNG via vendored `stb_image`; PPM is a fallback / edit-friendly format.
